# stable pointers

One pointer file per Distribution line (e.g. `stable/phoenix`), naming the newest production
Distribution on that line. The generator moves it when a stage changes — nobody edits it by
hand.

No pointer file exists yet: no Distribution line has a production Distribution.
`phoenix/v0.1-rc.1` is a partner-preview candidate, so `stable/phoenix` stays absent until a
production point exists on the phoenix line.
