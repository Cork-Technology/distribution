# phoenix/v0.4-rc.1 — draft candidate

This is a deployment candidate for review, not a published Distribution or an integration pin. Component versions and public tags remain pending. No existing component pin, Distribution manifest, or stable pointer changes.

## Scope

The candidate covers Phoenix core, ForSelf, Market Registry and Rollover on Base (8453) and Arbitrum (42161). The dependent command-line client, model context protocol interface and hosted API must adopt the new addresses and application binary interface (ABI) definitions before this candidate can become an integration pin. Deployment completion does not establish client compatibility or hosted-service activation.
